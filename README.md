# 짤·카드 스튜디오

이미지와 여러 한글 문구를 조합해 밈·카드·SNS용 이미지를 만드는 무로그인 공개 편집기입니다. PNG/JPEG 내보내기, 세 화면비, 사용자 템플릿, JSON 백업·복원을 지원합니다.

- **결과물:** https://card-studio-byungkwan.quannie70.chatgpt.site
- **소스 저장소:** https://github.com/LimByungKwan/Photo-Maker

## 사용 방법

1. **01 이미지**에서 본인이 제작했거나 사용 허가를 받은 PNG/JPEG를 불러옵니다.
2. **02 문구·글꼴**에서 문구를 추가하고 글꼴·위치·크기·색·테두리를 편집합니다. 1:1·4:5·9:16을 선택해 미리 봅니다.
3. **PNG 선택 / JPEG 선택** 후 **바로 저장 / 다른 이름으로 저장**을 선택합니다.

템플릿은 **03 템플릿**에서 이름을 입력해 새로 저장하고, 목록에서 불러오거나 삭제합니다. 수정은 템플릿을 불러와 편집한 후 **불러온 템플릿 덮어쓰기**를 누릅니다.

## 구현한 기능

- PNG/JPEG 파일명·MIME·파일 시그니처 확인, 이미지 디코딩 후 반영. 최대 10MB·2,000만 픽셀.
- 잘못된 파일은 이미지 영역에 이유를 표시하고 기존 이미지·문구를 유지합니다.
- 문구 최대 20개, 각 1,500자. 문구마다 위치·크기·색·글꼴·자동 맞춤·테두리 색을 독립 설정합니다.
- 한글·영문·명시적 줄바꿈·빈 줄·결합 이모지를 처리합니다. 긴 문구는 자동 줄바꿈·크기 및 위치 맞춤을 적용합니다.
- 기기에 설치된 맑은 고딕·굴림·바탕·궁서·돋움 계열 글꼴을 사용하며, 없으면 대체 글꼴을 사용합니다.
- 캔버스 실제 크기: 1:1 = 1080×1080, 4:5 = 1080×1350, 9:16 = 1080×1920.
- 동일한 편집 캔버스를 내보냅니다. PNG는 알파를 유지하고 JPEG는 투명 영역을 흰색으로 합성합니다.
- IndexedDB에 템플릿 저장. 이미지·화면비·문구 전체 설정과 생성·수정 시각을 보관합니다.
- 안정된 UUID로 수정·삭제 대상을 찾습니다. 목록 정렬이 바뀌어도 배열 위치로 대상을 선택하지 않습니다.
- JSON 전체 검증과 모든 이미지 디코딩·재인코딩 후 단일 DB 트랜잭션으로 추가합니다. 실패하면 기존 목록·작업을 유지합니다.
- 내보내기 JSON은 배경을 포함합니다. 가져오기는 새 ID를 생성하여 기존 목록에 추가합니다.
- 외부 이미지 URL이나 HTML을 실행하지 않으며, 이름·문구는 텍스트로 표시합니다. 파일을 서버로 전송하지 않습니다.

## 실제 검증 결과

관찰한 결과만 기록했습니다. 코드 검사, 사용자 캡처, 사용자 직접 보고는 구분합니다.

| 카드 | 확인 내용 | 결과·근거 |
|---|---|---|
| 1 | PNG/JPEG 불러오기·문구 편집·잘못된 입력 거부 | 사용자 편집·저장 검사 진행. 12번 검사에서 잘못된 PNG 거부 뒤 밤하늘·변경 문구 유지 캡처 확인 |
| 2 | 세 화면비와 내보낸 이미지 | 세 비율의 화면·파일 대조 진행. 글자 배치 회귀 계산 검사는 세 비율에서 통과하며 실제 브라우저를 대신하지 않음 |
| 3 | 극단 입력 12건·실제 결함 수정 | 12건 확인. 긴 한글 잘림과 투명 PNG 흰 배경의 수정 전 FAIL·수정 후 PASS 확보 |
| 4 | 템플릿 3개 생성·불러오기·수정·삭제 | 캡처 확인. 수정 때 3개 유지, 삭제 후 2개 유지 |
| 4 | 새로고침 유지 | 사용자 직접 확인 보고. 별도 새로고침 캡처는 제공되지 않음 |
| 5 | 정상·문법 손상·필수 누락 JSON | 정상 2→3개 복원. 잘못된 두 JSON은 오류 안내 후 기존 3개와 미리보기 유지 |
| 5 | 실제 배경 포함 JSON 백업 복원 | 12,766,371바이트 백업 구조·이미지3개 검사. 시크릿 창에서 0→3개 복원 캡처 확인. 기록 카드 실제 배경·문구·9:16 표시 |
| 5 | 완성 이미지 3개 | 아래 세 PNG의 전체 디코딩·크기·문구 확인. EXIF·GPS 0건 |

| 05 | 일반 이모지: 화면·파일 표시 | PASS |
| 06 | 가족·피부색·개발자 결합 이모지 | PASS. 줄 경계를 가로지르는 별도 분할 검사는 미실시 |

## 공개 안전 검사

- 최종 PNG3개: 전체 디코딩 성공, EXIF 태그0개, GPS 없음. PNG 청크는 IHDR·IDAT·IEND만 있으며 텍스트·EXIF 메타데이터 없음.
- 백업 내 배경3개: 전체 디코딩 성공, EXIF0개·추가 정보 없음.
- 최종 카드3개와 확인한 편집 화면에 실명·연락처·이메일·주소·계정 비밀값이 보이지 않음.
- 배포 정적 파일에서 API 토큰·GitHub 토큰·개인키 패턴 미검출. 최종 업로드 패키지도 검사하며 환경파일·인증정보·Git 내부 파일을 포함하지 않음.
- 개인 원본 파일명은 백업 JSON에서 제외합니다. 사용자가 앞으로 입력하는 정보까지 자동으로 안전하다고 보장하지 않습니다.
- 사용자 ID·이름이 포함된 GitHub 공개 계정 주소는 제출에 필요한 소스 식별자로 사용하며, 사적인 연락처는 넣지 않습니다.

## 저장 환경과 확인 한계

- 외부 브라우저와 시크릿 창에서 PNG/JPEG 저장 성공을 사용자가 확인했습니다.
- **GPT 내장 화면의 저장 실패는 해결 완료로 판정하지 않았습니다.** 공개 주소를 외부 브라우저에서 열어 저장합니다.
- '다른 이름으로 저장'은 지원 브라우저의 파일 저장 창을 사용합니다. 미지원·차단 환경에는 대체 안내가 표시됩니다. '바로 저장'의 저장 위치는 브라우저 설정에 따릅니다.
- 템플릿은 같은 브라우저·같은 사이트 주소의 IndexedDB에 저장됩니다. 다른 브라우저로 옮길 때 JSON을 사용합니다. 시크릿 창을 모두 닫거나 사이트 데이터를 지우면 없어질 수 있습니다.
- 웹폰트를 포함하지 않아 기기별 글꼴은 다를 수 있습니다.
- 이 작업 환경에서는 실제 브라우저 자동화를 실행하지 않았습니다. 사용자 캡처·파일 검사·Node 계산 검사에 근거를 나누어 기록했습니다.

## 재현·통과 확인 4줄

1. **위치:** 새 시크릿 창에서 공개 결과물 URL을 열고 01 이미지·02 문구·글꼴·03 템플릿을 확인합니다.
2. **행동(3단계):** ① PNG/JPEG 불러오기 ② 문구·화면비 편집 후 템플릿 저장 ③ PNG/JPEG 형식 선택 후 바로 저장 또는 다른 이름으로 저장합니다.
3. **통과 모습:** 미리보기와 파일의 배치가 일치하고, 템플릿을 새로고침 뒤 불러올 수 있으며 정상 JSON으로 배경·문구·비율이 복원됩니다.
4. **안 될 때 모습:** 잘못된 이미지·손상/필수 누락 JSON은 거부 이유를 표시하고 기존 목록·작업을 유지합니다. GPT 내부 저장이 막히면 공개 주소를 외부 브라우저에서 확인합니다.

## AI와 내 판단 3줄

1. **AI에게 맡긴 일:** 편집기 구현, 밤하늘 배경 생성, 글자 자동 맞춤·투명 PNG·템플릿·JSON 처리 개선, 코드·파일 검사와 기록 정리를 맡겼습니다.
2. **직접 판단한 일:** 여러 문구·글꼴·테두리 색과 저장 방식, 편집 영역 배치를 요청했고, 직접 입력·저장·템플릿 CRUD·시크릿 창 복원을 실행해 화면과 결과를 확인했습니다.
3. **AI 제안을 따르지 않은 일:** GPT 안에서도 저장 문제가 해결됐다는 판단을 그대로 받아들이지 않고 실패를 다시 알렸으며, 외부 시크릿 창에서 실제 저장되는지 확인했습니다.

## 로컬 확인·파일 구성

빌드 없이 `dist/index.html`을 브라우저로 열거나 정적 서버로 제공합니다. 원격 배포와 동일한 HTTPS 환경을 쓰면 브라우저 저장 기능을 확인하기 쉽습니다. GitHub Pages 사용 시 main 브랜치의 루트를 선택하면 루트 index.html이 dist/로 이동합니다. GitHub Pages 주소는 새로 배포한 후에만 결과 주소로 사용할 수 있으며 현재 확인한 결과 주소는 위 Sites URL입니다.

```text
index.html             GitHub Pages 루트 진입 파일
dist/                  공개 편집기 (HTML/CSS/JS)
  fixtures/            정상·문법 손상·필수 누락 JSON
examples/              검증한 최종 PNG 3개
docs/                  카드별 검사 기록
tests/                 Node 검사
README.md              프로젝트·근거·한계·제출문
SUBMISSION.md          제출 필드 복사용 초안
```

개발자가 선택적으로 실행할 검사:

```bash
node tests/text-layout.test.cjs
node tests/export-alpha.test.cjs
node tests/templates.test.cjs
node tests/backup.test.cjs
```

글자 폭 계산과 Canvas 분기 검사는 실제 화면의 글꼴 렌더링이나 브라우저 저장소 검사를 대신하지 않습니다.
