# 카드 3 검사 기록

실행 결과를 관찰한 항목만 기록한다. 미검사 항목을 PASS로 기재하지 않는다.

## 01 긴 한글 — 수정 전 FAIL / 수정 후 PASS

- 입력: 아래 문장을 공백으로 연결하여 5회 반복.
  `작은 시작이 모여 큰 변화를 만든다. 오늘도 나만의 속도로 한 걸음씩 나아간다.`
- 설정: 1:1, 80px, 가로 50%, 세로 50%, 문구 1개.
- 예상: 전체 문구가 이미지 안에 표시되고 미리보기와 PNG가 일치.
- 수정 전 실제: 미리보기와 PNG에서 상단과 하단 문장이 잘림. FAIL.
- 사용자 증거: 스크린샷 2026-10-15 090715.png, card-1x1 (1).png (2026-10-15 첨부).
- 수정: 문구별 자동 맞춤 옵션 추가. 전체 입력을 유지하며 높이와 폭을 기준으로 표시 크기를 줄이고 필요 시 표시 위치를 조정. 설정 크기와 실제 크기를 구분하여 표시. 사용자는 자동 맞춤을 해제할 수 있음.
- 계산 검사: `node tests/text-layout.test.cjs` 통과. Canvas 글자 폭은 근사 측정하므로 실제 브라우저 확인을 대신하지 않음.
- 수정 후 실제: 사용자 첨부 스크린샷 2026-10-15 091635.png와 card-1x1 (2)(1).png에서 동일 긴 문구/설정 80px/50%/50%/자동 맞춤 켜짐 확인. 실제 표시 50px, 전체 문구가 캔버스 안에 표시되고 미리보기와 PNG의 줄바꿈과 배치가 일치. PASS.

## 저장 환경 및 저장 방식

- 사용자 재확인: GPT 내부에서는 보조 기능 추가 후에도 저장 불가. 해결 완료로 판정하지 않음. 외부 브라우저/시크릿 창에서는 저장 성공 보고.
- PNG/JPEG 형식 선택 시 자동 다운로드하지 않도록 변경. 사용자가 바로 저장 또는 다른 이름으로 저장을 명시적으로 선택. 후자는 지원되는 외부 브라우저의 파일 저장 창 사용. 미지원 또는 차단 시 안내 표시.

## 11 투명 PNG — 수정 전 FAIL / 수정 후 PASS

- 입력: ChatGPT 생성 초승달과 별 투명 PNG(RGBA, 알파 0~255).
- 문구: 투명 이미지 검사. 화면비 1:1.
- 예상: PNG의 투명 영역 유지, 이미지와 문구의 배치가 미리보기와 일치.
- 수정 전 증거: 스크린샷 2026-10-15 100953.png, card-1x1 (13).png.
- 실제: 미리보기는 투명하지만 PNG는 흰색 배경. 저장 PNG 알파 범위 255~255. FAIL.
- 원인: PNG/JPEG 모두 같은 흰 배경 합성 캔버스로 내보냄.
- 수정: 형식별 별도 캔버스 생성. PNG는 알파 유지, JPEG에만 흰색 배경 합성.
- 수정 후 증거: 스크린샷 2026-10-15 101559.png, card-1x1 (14).png. 그림·문구 배치 일치. PNG 1080×1080 RGBA, 알파 0~255, 모서리 (0,0,0,0). PASS.
