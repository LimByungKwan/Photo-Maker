# 카드 5 — 옮겨 쓰기와 완성본

## JSON 계약

`app: "card-studio"`, `version: 1`, `templates: [...]`.
각 템플릿: id, name, createdAt, updatedAt, scene(ratio, backgroundMode, texts, imageData).
문구: id, caption, x, y, size, color, font, fit, outline, outlineColor.
배경: sample/blank는 imageData:null, image는 내장 PNG data URL.
개별 원본 파일명은 JSON에 포함하지 않는다.
한 파일 30MB, 한 번에 1~50개, 문구 최대20개·각1500자, 이미지 최대2,000만 픽셀.

1. JSON 파싱과 모든 항목·범위·ID 중복·형식·PNG 헤더/크기를 검증.
2. 모든 배경 이미지 디코딩 및 캔버스 PNG 재인코딩으로 원본 메타데이터를 복사하지 않음.
3. 전부 통과하면 새 ID를 부여하여 단일 IndexedDB 트랜잭션의 add로 저장.
4. 오류 시 목록을 지우지 않고 기존 편집 화면도 바꾸지 않음.
5. 정상 복원은 기존 목록에 추가하므로 반복 가져오기 시 복사본이 늘어남. UI에 명시.

## 검사 상태

- Node: 백업 왕복, 새 ID, 손상 문법, 필수 항목 누락, 뒤쪽 레코드 오류, 이미지 디코딩 실패 시 준비 전체 거부 통과.
- 기존 템플릿·텍스트 배치·PNG/JPEG 캔버스 검사 통과.
- 실제 브라우저 C22~C24: 사용자 캡처로 확인 완료.
- C25~C28: 최종 이미지3개 검사 및 파일별 제작기록 작성 완료. 아래 결과와 README 참고.
- C29~C30: 최종 화면·소스·제출문 확정 후 검사. 새 JSON 코드에서 가져온 문구/이름은 textContent로 표시하며 HTML 실행하지 않음.
- C31~C32: 결과·40자리 고정 소스 URL 확정 후 최종 제출문 작성.

## 실제 확인 순서

현재 템플릿 2개를 기준으로:

1. 03 템플릿의 '전체 템플릿 JSON 준비' → '준비된 JSON 내려받기'로 본인 백업 보관.
2. '검사용 JSON 파일 3종'에서 정상/문법 손상/필수 누락 파일 내려받기.
3. 정상 valid.json 가져오기: 'JSON 복원 검사'가 추가되어 2→3개. 불러오면 기본 합성 배경·4:5·'JSON 복원 성공!' 표시. C22.
4. broken.json 가져오기: 문법 손상 이유·가져오기 거부·기존3개 유지. C23.
5. missing.json 가져오기: 필수 항목 누락 이유·가져오기 거부·기존3개 유지. C24.
6. 이후 본인 백업 JSON으로도 배경 이미지와 모든 문구 설정이 복원되는지 확인.

정상 검사용 배경은 편집기를 위해 코드로 제작한 합성 이미지다. 최종 AI 생성 밤하늘 사용 시 'ChatGPT 생성 배경 / 본인 문구·배치 편집'으로 역할을 기록하며, 과거 검토했던 네이버 이미지를 본인 제작으로 기록하지 않는다.
